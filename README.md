# Did They Collude or Just Agree? What Counts as Evidence of Collusion Among AI Reviewers

**Jan Samuel Matuba**, Independent Researcher. Apart AI Collusion Research Sprint, 2026-10-23 to
2026-10-25, Track 2 (Detection and Audit of Collusion), research question 2.3.

Two reviewers vouch for a claim, and the claim turns out to be false. Did they collude, or only
agree? A shared source, copying, a persuasive proposer, and a shared incentive all leave the same
records. This project is a small review game (a proposer, two reviewers, a decider, and an auditor
who reads the record later) in which each cause of agreement is a switch. Seven language models
played every role, 288 plays each, after a frozen preregistration. The private channel never
increased false approvals; words did not predict actions; provenance data had almost nothing to
correct; one pact in 108 classified records changed an action, and only the twin record without
the channel exposed it. Harm alone and messages alone are not evidence of collusion.

## Reproduce

```
cd lab
uv sync
uv run pytest
uv run elab demo --seeds 5 --boot 2000                     # scripted agents, no API key
uv run elab llm --split heldout --seeds 3 --run-id my-run  # needs lab/.env (see .env.example)
uv run python ../projects/2026-10-apart-collusion-sprint/report/model_table.py mine=my-run
```

Appendix C of the paper lists every command, setting, and cost. The raw trajectories and the API
cache are not in git; they are available on request. API keys live only in git-ignored
`lab/.env*` files.

## Preexisting work and LLM usage (sprint rule)

The research question and the framework (the review game, the eight settings, the five causes of
agreement, the plus-factor idea, the reading list) were worked out in the week before the sprint,
as notes. No code, prompts, runs, or results existed before the sprint. Everything in this
repository was made during the sprint: the `lab/` code, the preregistration, all runs, the
classification, the analysis, the figures, and the report. AI assistants (Claude Code; ChatGPT for
ideas) were used for code, analysis, and text, and an AI assistant classified the 108 E1
trajectories with fixed criteria that the author spot-checked. The author is responsible for every
claim. Full disclosure: Appendix B of the paper.
